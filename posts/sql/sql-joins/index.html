SQL Joins as Set Relationships

A join combines rows by a relationship between keys. The join type determines which unmatched rows survive.

July 4, 2026•Ahamed Learning Notes

Instead of memorizing join diagrams, ask which table must keep all of its rows and what condition connects the two sides.

INNER JOIN

An inner join keeps only rows that find a match on both sides.

SELECT students.name, courses.title
FROM students
INNER JOIN enrollments
    ON students.id = enrollments.student_id
INNER JOIN courses
    ON courses.id = enrollments.course_id;

LEFT JOIN

A left join preserves every row from the left table. When no matching right row exists, right-side columns become NULL.

Useful check: if your question includes even those with none, you probably need an outer join.
