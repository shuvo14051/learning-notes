Rand Index and Adjusted Rand Index, Pair by Pair

Compare two clusterings by asking one small question about every pair of observations: do both clusterings agree about whether the pair belongs together?

September 4, 2026 •Ahamed Learning Notes

Why compare pairs?

Cluster names are arbitrary. A predicted cluster called 0 can correspond perfectly to a true cluster called 2. Comparing label values directly would therefore be wrong. RI and ARI instead compare the relationships between every unordered pair of observations.

Predicted cluster labels [0, 0, 1, 2, 1]
Ground-truth labels [2, 2, 3, 3, 1]

With five rows there are C(5, 2) = 10 distinct pairs. For each pair, “positive” means the predicted labels place the two rows in the same cluster; “negative” means they are in different predicted clusters.

TP, FP, TN, and FN for clustering

Treat the prediction as the decision being tested. For each pair, it predicts either same cluster (positive) or different clusters (negative). The ground truth tells us whether that decision is correct.

TP — true positive
Prediction sayssame cluster
Ground-truth sayssame cluster

A correct merge: both clusterings keep the pair together.

FP — false positive
Prediction sayssame cluster
Ground-truth saysdifferent clusters

A wrong merge: the prediction joins a pair that should be separate.

TN — true negative
Prediction saysdifferent clusters
Ground-truth saysdifferent clusters

A correct separation: both clusterings keep the pair apart.

FN — false negative
Prediction saysdifferent clusters
Ground-truth sayssame cluster

A missed merge: the prediction separates a pair that belongs together.

The only test needed: for pair (i, j), compare pred[i] == pred[j] with true[i] == true[j]. Equal decisions are agreements; unequal decisions are disagreements.

Compute the Rand Index

RI is simply the fraction of pair decisions on which the two clusterings agree. The agreements are TP and TN.

RI = TP + TN TP + FP + TN + FN
= 1 + 7 1 + 1 + 7 + 1 = 810 = 0.80

Raw RI implementation

def rand_index_raw(labels_true, labels_pred):
    """Compute RI and its TP/FP/TN/FN pair counts."""
    if len(labels_true) != len(labels_pred):
        raise ValueError("Both label sequences must have the same length")

    tp = fp = tn = fn = 0

    for i in range(0, len(labels_pred) - 1):
        for j in range(i + 1, len(labels_pred)):
            if labels_pred[i] == labels_pred[j]:
                # Positive pair
                if labels_true[i] == labels_true[j]:
                    tp += 1  # True positive
                else:
                    fp += 1  # False positive
            else:
                # Negative pair
                if labels_true[i] == labels_true[j]:
                    fn += 1  # False negative
                else:
                    tn += 1  # True negative

    total_pairs = tp + fp + tn + fn
    ri = (tp + tn) / total_pairs if total_pairs else 1.0
    return ri, {"TP": tp, "FP": fp, "TN": tn, "FN": fn}


y_pred = [0, 0, 1, 2, 1]
y_true = [2, 2, 3, 3, 1]

ri, counts = rand_index_raw(y_true, y_pred)
print(ri)
print(counts)

Output:

0.8
{'TP': 1, 'FP': 1, 'TN': 7, 'FN': 1}

RI with scikit-learn

In practice, rand_score computes the same Rand Index directly from the two label sequences. 

from sklearn.metrics import rand_score


y_pred = [0, 0, 1, 2, 1]
y_true = [2, 2, 3, 3, 1]

ri = rand_score(y_true, y_pred)
print(ri)

Output:

0.8

Why RI needs adjustment

RI rewards both same-cluster and different-cluster agreements. When a dataset has many clusters, most pairs are separate, so two unrelated clusterings can collect many TN agreements merely by chance. ARI removes the agreement expected from random clusterings that preserve the two observed cluster-size distributions.

ARI = RI − E[RI] 1 − E[RI]

The numerator is agreement above chance. The denominator is the greatest possible improvement over chance. Consequently, perfect agreement gives ARI = 1, chance-level agreement is near 0, and worse-than-chance agreement can be negative.

Focus: where does E[RI] come from?

Use a larger example so the true classes and predicted clusters have visibly different sizes. We have 9 samples:

Ground-truth labels [A, A, A, A, A, B, B, B, C]
Predicted cluster labels [0, 0, 0, 1, 1, 0, 2, 3, 2]

Step 1: make the groups explicit

GroupingMembersSizes
Ground truthA = {1, 2, 3, 4, 5}
B = {6, 7, 8}

Prediction0 = {1, 2, 3, 6}

3 = {8}		4, 2, 2, 1

Therefore Ktrue = 3 and Kpred = 4. The numbers of groups and their sizes differ. The total number of unordered sample pairs is:

M = C(9, 2) = 36

Step 2: count same and different pairs

The ground-truth classes contain this many same-class pairs:

T = C(5, 2) + C(3, 2) + C(1, 2)
= 10 + 3 + 0 = 13
Pr(same in truth) = 1336
Pr(different in truth) = 2336

The predicted clusters contain this many same-cluster pairs:

P = C(4, 2) + C(2, 2) + C(2, 2) + C(1, 2)
= 6 + 1 + 1 + 0 = 8
Pr(same in prediction) = 836
Pr(different in prediction) = 2836

Step 3: calculate E[RI] from pair probabilities

Chance agreement has two parts: both clusterings say same, or both say different. Add those two probabilities:

E[RI] = Pr(same truth) × Pr(same prediction)
+ Pr(different truth) × Pr(different prediction)
= 1336 × 836 + 2336 × 2836
= 0.0802 + 0.4969 ≈ 0.577

1. Cells give the observed TP count

A cell counts samples that share both a predicted cluster and a true class. Pred 0 ∩ Truth A contains samples {1, 2, 3}, contributing C(3, 2) = 3 TP pairs. Pred 1 ∩ Truth A contains {4, 5}, contributing one more. All remaining cells contain at most one sample and contribute zero.

TP = Σ C(cell count, 2) = C(3, 2) + C(2, 2) = 4

2. Margins give all same-pair totals

Column totals [5, 3, 1] reproduce the ground-truth total T = 13. Row totals [4, 2, 2, 1] reproduce the prediction total P = 8.

T = Σ C(column total, 2) = 13
P = Σ C(row total, 2) = 8

3. Complete the observed pair counts

FP = P − TP = 8 − 4 = 4
FN = T − TP = 13 − 4 = 9
TN = M − TP − FP − FN = 36 − 4 − 4 − 9 = 19
RI = TP + TNM = 4 + 1936 ≈ 0.639

4. Adjust the observed RI

The observed RI is about 0.639, while chance alone is expected to produce about 0.577. ARI measures the improvement above that chance baseline.

ARI = RI − E[RI]1 − E[RI]
= 0.639 − 0.5771 − 0.577 ≈ 0.146

ARI with scikit-learn

from sklearn.metrics import adjusted_rand_score


y_true = ["A", "A", "A", "A", "A", "B", "B", "B", "C"]
y_pred = [0, 0, 0, 1, 1, 0, 2, 3, 2]

ari = adjusted_rand_score(y_true, y_pred)
print(round(ari, 3))

Output:

0.146
Takeaway

RI asks how often two clusterings make the same pair decision. ARI asks how much better that agreement is than the agreement expected by chance under the observed cluster sizes. Prefer ARI when comparing clustering quality across realistic experiments.
