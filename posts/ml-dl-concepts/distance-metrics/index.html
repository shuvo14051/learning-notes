Distance Measures in Machine Learning

Euclidean, Manhattan, Minkowski, cosine, Hamming, and Jaccard — six ways to decide what is close.

September 8, 2026•Ahamed Learning Notes

Distance defines what “near” means to a machine learning model. Straight-line separation, direction, mismatched positions, and set overlap answer different questions. Here are six common distances, with formulas and worked examples.

Point A(2, 3)
Point B(5, 7)

We will reuse these two points for Euclidean, Manhattan, and Minkowski distance, and compare their directions with cosine. The other examples show what changes when we compare measurements, documents, bits, or sets.

For numeric vectors, write x = (x1, x2, …, xd) and y = (y1, y2, …, yd), where d is the number of features.

1. Euclidean distance

Euclidean distance is the shortest straight-line distance between two points. It uses both the direction and size of the coordinate differences.

d2(x,y)=d∑i=1(xi−yi)2
In 2D: d2(x,y)=(x1−y1)2+(x2−y2)2

Example: the same two points

Let A = (2, 3) and B = (5, 7). Subtract coordinates first: 5 − 2 = 3 and 7 − 3 = 4.

d2(A,B)=(5−2)2+(7−3)2
=9+16=5

When it is useful

Use it when features are numeric and their magnitudes matter.

  • K-means clustering (its objective uses squared Euclidean distances)
  • KNN
  • Image pixel vectors
  • Embedding vectors in some settings
  • Geometric data and coordinates

Think of two locations on a map: what is the shortest straight-line distance between them?

Important problem: feature scale

Features: [age, salary].

Person A[25, 50000]
Person B[30, 60000]
Watch the feature scales

For [age, salary], compare [25, 50000] with [30, 60000]. The salary difference of 10000 overwhelms the age difference of 5. Scale features when comparable influence is appropriate; choose scaling that reflects the meaning of the data.

2. Manhattan distance

Also called L1, taxicab, or city-block distance, Manhattan distance adds the absolute differences along each coordinate.

d1(x,y)=d∑i=1|xi−yi|

Example: the same two points

Again, A = (2, 3) and B = (5, 7).

d1(A,B)=|5−2|+|7−3|=7

Imagine walking along city streets: travel 3 blocks horizontally and 4 vertically. The route has length 7, while the Euclidean diagonal has length 5.

When it is useful

Manhattan is useful when differences add independently along dimensions.

  • Grid-based movement
  • Sparse data
  • High-dimensional data
  • Some settings where large coordinate deviations should have less relative influence
  • Nearest-neighbor methods

The best choice depends on the task, and feature scaling still matters.

3. Minkowski distance

Minkowski is a family of distances controlled by p. For a metric, use p ≥ 1.

dp(x,y)=(d∑i=1|xi−yi|p)1p
p=1:d1(x,y)=d∑i=1|xi−yi|=dManhattan(x,y)
p=2:d2(x,y)=d∑i=1(xi−yi)2=dEuclidean(x,y)

Example with p = 3

Keep A = (2, 3) and B = (5, 7). The absolute differences remain 3 and 4; now cube them: 33 = 27 and 43 = 64.

d3(A,B)=(|5−2|3+|7−3|3)13
=9113≈4.50
(27 + 64)13 = 9113 ≈ 4.50

Higher p gives the largest coordinate differences more relative influence. At p = 1, each absolute difference contributes additively. KNN can use p to choose the geometry of its neighborhood.

4. Cosine distance

Cosine compares direction rather than magnitude. For two nonzero vectors, first calculate cosine similarity, then subtract it from 1.

similarity(x,y)=x·y‖x‖2‖y‖2
x·y=d∑i=1xiyi
dcos(x,y)=1−similarity(x,y)

Example: directions of the same two points

For A = (2, 3) and B = (5, 7), the dot product is 2 × 5 + 3 × 7 = 31.

similarity(A, B) = 3122 + 32 × 52 + 72
= 3113 × 74 ≈ 0.99948
Cosine distance ≈ 1 − 0.99948 = 0.00052

The points are 5 Euclidean units apart, but their vectors from the origin point in nearly the same direction.

Same direction, different lengths

A = [1, 2] and B = [2, 4] = 2A. Their Euclidean distance is 5, but their direction is identical.

similarity(A,B)=105×20=1
dcos(A,B)=0

Real example: documents

Vocabulary: [AI, model, biology].

Document A[10, 20, 0]
Document B[100, 200, 0]

Using the vocabulary [AI, model, biology], represent document A as [10, 20, 0] and B as [100, 200, 0]. B has ten times the counts, but exactly the same proportions. Their cosine similarity is exactly 1 and their cosine distance is 0.

Euclidean = (100 − 10)2 + (200 − 20)2 + 02
= 40500 ≈ 201.25
Cosine similarity = 1; cosine distance = 0

Cosine is widely used in:

  • Document similarity and NLP
  • Embeddings and semantic search
  • Recommendation systems
  • Image embeddings, including CLIP embeddings

Euclidean asks: how far apart are these points? Cosine asks: are these vectors pointing in the same direction?

Direction has a few caveats

A zero vector has no direction, so the formula is undefined for it. Cosine distance ranges from 0 to 2 for general real vectors; nonnegative word counts restrict it to 0 through 1. The common definition 1 − cosine similarity is not a mathematical metric because it can violate the triangle inequality.

5. Hamming distance

For equal-length sequences, count the positions where the values differ.

dH(x,y)=d∑i=1I(xi≠yi)

The indicator I is 1 when the values differ and 0 otherwise.

Example

A = [1, 0, 1, 1, 0] and B = [1, 1, 1, 0, 0]. Only positions 2 and 4 differ.

dH(A,B)=2

When it is useful

Hamming is useful for:

  • Binary strings and bit vectors
  • Error-correcting codes
  • Aligned DNA sequences of equal length
  • Categorical vectors
  • Hashing

Bit-string example

String A1011101
String B1001001

Comparing the seven-bit strings, positions 3 and 5 differ: two bits must change.

Hamming distance = 0 + 0 + 1 + 0 + 1 + 0 + 0 = 2

Some implementations return the mismatch proportion instead of the count. For the five-position example, Normalized Hamming distance is 25=0.4.

6. Jaccard distance

Jaccard compares sets or binary presence/absence data. It measures shared items relative to all distinct items present in either set.

J(A,B)=|A∩B||A∪B|
dJ(A,B)=1−J(A,B)

Example: watched movies

User A{Avatar, Titanic, Interstellar}
User B{Titanic, Interstellar, Dune}

A = {Avatar, Titanic, Interstellar}
B = {Titanic, Interstellar, Dune}

The intersection is {Titanic, Interstellar}, with 2 movies. The union is {Avatar, Titanic, Interstellar, Dune}, with 4 movies.

J(A,B)=24=0.5
dJ(A,B)=1−0.5=0.5

When it is useful

Jaccard is useful for:

  • Recommendation systems and item overlap
  • Document word sets
  • Binary feature vectors
  • Customer purchase histories
  • Biological species sets
  • Overlap between the members of two clusters

It focuses on what is present in at least one set.

For binary features, shared zeros do not count toward overlap: two users both skipping a movie adds no shared interest. If both sets are empty, the ratio is 00; a common convention defines their similarity as 1 and distance as 0.

Choose what “similar” should mean

Euclidean measures straight-line separation. Manhattan adds coordinate differences. Minkowski controls this geometry with p. Cosine compares directions, Hamming counts mismatches, and Jaccard compares set overlap.
