What Is a Bound Method in Python?

See how a function stored on a class becomes connected to an instance—and why Python passes self automatically.

August 26, 2026 • Ahamed Learning Notes

In Python, an instance method begins as a function stored in a class. When you access that function through an instance, Python produces a bound method that remembers both the function and the instance.

Bound method = function + instance. Calling the bound method passes its instance as the first argument automatically.

1. Start with a plain function

A regular function receives every argument explicitly.

def greet(name):
    print("Hi", name)


greet("Ahamed")

Nothing is attached automatically here. The call supplies the value for name directly.

2. Put a function inside a class

A function defined in a class body is stored in the class namespace. 

class Person:
    def greet(self):
        print("Hi", self)


print(Person.__dict__["greet"])

The output looks similar to this:

<function Person.greet at 0x...>

The value stored directly in Person.__dict__ is a function object. It has not been bound to an instance.

3. Access it through the class and the instance

p = Person()

print(Person.greet)
print(p.greet)

The output has two different forms:

<function Person.greet at 0x...>
<bound method Person.greet of <__main__.Person object at 0x...>>

Access through the class

Person.greet(p)

Person.greet gives you the function. You pass p manually as its first argument.

Access through the instance

p.greet()

p.greet gives you a bound method. It already remembers p, so Python supplies that object as the first argument when the method is called.

Calling p.greet() has the same effect as calling Person.greet(p) in this example.

4. What “bound” actually means

A bound method remembers two important objects:

  • the original function, available as p.greet.__func__
  • the attached instance, available as p.greet.__self__
method = p.greet

print(method.__func__ is Person.greet)  # True
print(method.__self__ is p)             # True

When method() runs, the method calls its stored function with its stored instance as the first argument.

5. When does binding happen?

Binding does not happen when the class is defined or when the instance is created. It happens when the method attribute is accessed through the instance.

For an ordinary instance method, the important sequence is:

  1. Python evaluates an attribute access such as p.greet.
  2. It finds the function through the class.
  3. The function's descriptor behavior creates a method bound to p.

The descriptor protocol is the mechanism behind this automatic transformation. It is also why different descriptors—such as properties, class methods, and static methods—behave differently during attribute access.

6. Why is self required?

class A:
    def hello():
        print("hi")


a = A()
a.hello()

Accessing a.hello creates a method bound to a. Calling it then passes a to hello, but the function declares no parameter to receive it. Python raises a TypeError. 

TypeError: A.hello() takes 0 positional arguments but 1 was given
self is not a special keyword. It is the conventional name for the first parameter that receives the bound instance.

7. Each access can produce a new method object

print(p.greet is p.greet)  # Usually False

The two attribute accesses can produce two separate bound method objects. They are temporary wrappers around the same function and instance.

Comparing printed id() values in two separate expressions can be misleading because a temporary method object may be discarded and its memory reused. Store both methods first if you want to demonstrate their identities clearly: 

first = p.greet
second = p.greet

print(first is second)  # False
print(first == second)  # True
print(id(first))
print(id(second))

Although the wrapper objects differ, bound methods compare equal when they contain the same function and instance.

Summary

  • Person.__dict__["greet"] is the stored function.
  • Person.greet accesses that function through the class.
  • p.greet produces a method bound to p.
  • p.greet() behaves like Person.greet(p).
  • Binding happens during instance attribute access.
Once bound methods make sense, instance methods, class methods, static methods, and descriptors become much easier to reason about.
