Insert at a Given Index

Insert a new node between two existing nodes without losing the remainder of a singly linked list.

August 30, 2026 • Ahamed Learning Notes

01 — Overview

Insert the new node between two existing nodes

def insert_at_index(self, index, data):
    if index < 0 or index > self.size:
        raise IndexError("Index out of range")

    if index == 0:
        self.insert_at_beginning(data)
        return

    new_node = Node(data)
    current_node = self.head

    for _ in range(index - 1):
        current_node = current_node.next

    new_node.next = current_node.next
    current_node.next = new_node
    self.size += 1

Inserting at a given index requires finding the node immediately before the insertion position. Suppose the list contains A → B → C, and we want to insert X at index 2.

02 — Follow the references

Eight steps to insert safely

1 Validate the index

if index < 0 or index > self.size:
    raise IndexError("Index out of range")

A list of size 3 accepts insertion indices 0 through 3. An index below 0 or above 3 is invalid.

2 Handle index zero

if index == 0:
    self.insert_at_beginning(data)
    return

Index 0 changes the head. Reusing the existing method also avoids increasing self.size twice.

3 Create the new node

new_node = Node(data)

This creates X. Its next reference is initially None, so it is not connected yet.

4 Start at the head

current_node = self.head

current_node is a temporary traversal reference. The actual head does not move.

5 Find the previous node

for _ in range(index - 1):
    current_node = current_node.next

For index 2, the loop runs once and moves from A to B—the node immediately before the insertion position.

6 Point X to C

new_node.next = current_node.next

Since current_node is B, this makes X point to C. B still points to C, so no part of the list is lost.

7 Point B to X

current_node.next = new_node

B now points to X instead of directly to C. The new node is part of the chain: A → B → X → C.

8 Update the size

self.size += 1

The list previously contained three nodes and now contains four.

04 — Connection order

Why the two assignments must stay in order

new_node.next = current_node.next
current_node.next = new_node

First connect X to C. Then connect B to X. If B's next reference is replaced first, the reference to C can be lost and the new node may even point to itself.

Before: B → C
First connection: X → C
Second connection: B → X → C

05 — Complexity

The traversal determines the running time

Time complexity: O(n). The method may traverse the list to find the node before the requested index. Once that node is found, the two reference changes take O(1) time.
Key idea: Preserve the next node first. Connect the new node forward, and only then connect the previous node to it.
