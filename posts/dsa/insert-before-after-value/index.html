Insert Before or After a Value

Find a target node, then change the surrounding references to place a new node immediately before or after it.

September 2, 2026 • Ahamed Learning Notes

01 — Overview

Use a value instead of an index

In Part 3, we traversed the list until we reached a particular index. Here, we traverse until we find a node whose data equals target. Suppose the list is A → B → C and the target is B.

Insert after B: A → B → X → C
Insert before B: A → X → B → C

Both methods insert beside the first matching value and return immediately. If the target does not exist, the list stays unchanged.

02 — Insert after a value

Find the target and connect the new node after it

def insert_after_value(self, target, data):
    current_node = self.head

    while current_node:
        if current_node.data == target:
            new_node = Node(data)
            new_node.next = current_node.next
            current_node.next = new_node
            self.size += 1
            return

        current_node = current_node.next

Inserting after the last node needs no special case. Its next is None, so the new node simply becomes the new last node.

03 — Insert before a value

Stop at the node before the target

def insert_before_value(self, target, data):
    if self.head is None:
        return

    if self.head.data == target:
        self.insert_at_beginning(data)
        return

    current_node = self.head

    while current_node.next:
        if current_node.next.data == target:
            new_node = Node(data)
            new_node.next = current_node.next
            current_node.next = new_node
            self.size += 1
            return

        current_node = current_node.next

Visual example: insert X before B

Again, start with A → B → C. This time we must stop at A, because A is the node immediately before target B.

head, current_node ↓    target = B
Anext
→
Bnext
→
Cnext
→ None

1 Handle an empty list

if self.head is None:
    return

An empty list contains no target, so there is nowhere to insert the new value.

2 Handle a target at the head

if self.head.data == target:
    self.insert_at_beginning(data)
    return

There is no previous node when the head is the target. Reusing insert_at_beginning updates both the head and the size.

3 Look one node ahead

while current_node.next:
    if current_node.next.data == target:

To insert before B, current_node must stop at A. Looking at current_node.next.data lets us detect B while keeping a reference to the node before it.

current_node: A
current_node.next: B, the target

4 Insert between the two nodes

new_node = Node(data)
new_node.next = current_node.next
current_node.next = new_node

First X points to B. Then A points to X. The connection order preserves B and everything after it.

First connection: X.next points to B

→ None

Important: use while current_node.next. If the loop only checks current_node, it can reach the last node and then try to read current_node.next.data from None.

04 — Compare the operations

Where should traversal stop?

OperationStop atMain link change
Insert after target The target node target.next = new_node
Insert before target The node before the target previous.next = new_node

05 — Complexity and behavior

The search determines the running time

Time complexity: O(n). In the worst case, each method checks every node. Creating and connecting the new node takes O(1) time once the target is found.

The methods use O(1) extra space. If values are repeated, only the first matching target is used because the method returns immediately after inserting.

06 — Try both methods

Example calls

# Starting list: A -> B -> C
linked_list.insert_after_value("B", "X")
# Result: A -> B -> X -> C

linked_list.insert_before_value("B", "Y")
# Result: A -> Y -> B -> X -> C
Key idea: To insert after a value, stop on the target. To insert before a value, stop one node earlier. Always connect the new node forward before changing the existing link.
