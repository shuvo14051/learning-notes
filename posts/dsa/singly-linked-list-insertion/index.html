Singly Linked List Insert Operations

Learn how references move when a new node is inserted at the beginning or at the end of a singly linked list.

August 21, 2026 • Ahamed Learning Notes

01 — Overview

Two places to insert a node

A singly linked list stores a reference to its first node in self.head. Each node stores a reference to the next node. To insert a value, we create a new node and connect it to the existing chain without losing any references.

Beginning: connect the new node to the old head, then make it the new head.
End: follow the links to the last node, then connect the new node after it.

02 — Insert at the beginning

Make the new node the head

def insert_at_beginning(self, data):
    new_node = Node(data)

    if self.head:
        new_node.next = self.head

    self.head = new_node
    self.size += 1

Inserting at the beginning changes the head of the list. Suppose the current list starts with A and we want to insert X.

1 Create the new node

new_node = Node(data) creates X. Its next reference is initially None.

Xnext
→ None

2 Point to the old head

If the list is not empty, new_node.next = self.head connects X to A. The existing list remains reachable through X.

new_node ↓
Xnext
→
Anext
→
Bnext
→ None

3 Move the head

self.head = new_node makes X the first node. This line also works when the list is empty.

head ↓
Xnext
→
Anext
→
Bnext
→ None

4 Update the size

self.size += 1 records that the list now contains one more node.

Time complexity: O(1). Inserting at the beginning takes the same amount of work no matter how many nodes are in the list.

03 — Insert at the end

Find the last node and connect the new node

def insert_at_end(self, data):
    new_node = Node(data)

    if self.head:
        current_node = self.head

        while current_node.next:
            current_node = current_node.next

        current_node.next = new_node
    else:
        self.head = new_node

    self.size += 1

Inserting at the end requires us to find the last node. Suppose the list contains A → B and we want to insert X.

1 Create the new node

new_node = Node(data) creates X. Because X will be last, its next reference can stay None.

2 Start at the head

When the list is not empty, current_node = self.head gives us a temporary reference for walking through the list. The head itself does not move.

head, current_node ↓
Anext
→
Bnext
→ None

3 Walk to the last node

The loop continues while current_node.next exists. It stops at B because B's next reference is None. 

while current_node.next:
    current_node = current_node.next

4 Attach the new node

current_node.next = new_node replaces the last node's None reference with a reference to X.

head ↓
Anext
→
Bnext
→
Xnext
→ None

5 Handle an empty list

If self.head is None, there is no last node to find. The new node becomes the head instead. Finally, the method increases self.size in both cases.

Time complexity: O(n). Without a separate tail reference, the method may need to visit every node to reach the end of the list.

04 — Compare the operations

What changes?

Operation Main reference change Time
Insert at beginning self.head = new_node O(1)
Insert at end last_node.next = new_node O(n)

05 — Put it together

Complete code

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


class LinkedList:
    def __init__(self):
        self.head = None
        self.size = 0

    def insert_at_beginning(self, data):
        new_node = Node(data)

        if self.head:
            new_node.next = self.head

        self.head = new_node
        self.size += 1

    def insert_at_end(self, data):
        new_node = Node(data)

        if self.head:
            current_node = self.head

            while current_node.next:
                current_node = current_node.next

            current_node.next = new_node
        else:
            self.head = new_node

        self.size += 1


linked_list = LinkedList()
linked_list.insert_at_beginning("B")
linked_list.insert_at_beginning("A")
linked_list.insert_at_end("C")
linked_list.insert_at_end("D")
Key idea: Insert at the beginning by changing the head. Insert at the end by keeping the head in place and changing the last node's next reference.
