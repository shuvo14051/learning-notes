What Is the Use of if __name__ == "__main__"?

Control whether code runs only when a Python file is executed directly or stays quiet when the file is imported.

August 31, 2026•Ahamed Learning Notes

A Python file can be used in two different ways. You can run the file itself as a program, or you can import it so another file can reuse its functions and classes. The line if __name__ == "__main__" helps Python code behave differently in those two situations.

Put reusable definitions outside this condition. Put actions such as asking for input, printing results, or starting the program inside it. Those actions then run only when the file is executed directly and stay quiet when the file is imported into another file.

Why This Problem Exists

In Python, when you import a file, Python executes that file from top to bottom. That means any print statements, input calls, or function calls sitting in the main body of the file will run immediately.

That becomes a problem when you want to reuse functions from one file inside another file.

Example Without __main__

calculator.py

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

print("This is a simple calculator")

x = int(input("Enter first number: "))
y = int(input("Enter second number: "))

print("Sum:", add(x, y))
print("Difference:", subtract(x, y))

program.py

import calculator

print("Using the calculator module")
print(calculator.add(10, 5))

You might expect program.py to just print:

Using the calculator module
15

But that is not what happens.

Since Python executes the entire imported file, importing calculator also runs its print statements and input calls. So program.py unexpectedly starts behaving like an interactive calculator.

For example, if the user enters 8 and 3, the actual output is: 

This is a simple calculator
Enter first number: 8
Enter second number: 3
Sum: 11
Difference: 5
Using the calculator module
15

The first five lines come from calculator.py while it is being imported. Only after that file finishes running Python return to program.py and print its final two lines. The import was meant to provide add(), but it also started the calculator because those actions were left at the top level.

The Fix: if __name__ == "__main__"

This is exactly why Python uses the if __name__ == "__main__" pattern. It protects code that should only run when the file itself is executed directly.

calculator.py

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

if __name__ == "__main__":
    print("This is a simple calculator")

    x = int(input("Enter first number: "))
    y = int(input("Enter second number: "))

    print("Sum:", add(x, y))
    print("Difference:", subtract(x, y))

Now the calculator logic only runs when calculator.py is executed directly. If you import it from another file, only the function definitions are loaded.

What Is __name__?

Before Python executes a file, it automatically gives that file a variable called __name__. Think of it as a label that tells the file, "How am I being used right now?"

When calculator.py is the file you asked Python to run, it is the program's starting point. Python gives it the special label "__main__": 

# Command
python calculator.py

# Value inside calculator.py
__name__ == "__main__"

When program.py imports calculator.py, the calculator file is no longer the starting point. It is a module named calculator, so Python uses that module name as the label: 

# Code inside program.py
import calculator

# Value inside calculator.py during the import
__name__ == "calculator"

Now read the condition like a normal question: "Is this file the program being run directly?" 

if __name__ == "__main__":
    # Run this only when this file is the starting point
    ...

During a direct run, the comparison is true, so the indented code runs. During an import, the comparison is false, so Python skips that block. The functions above it are still defined and can be used by the importing file.

Direct Run vs Import

When you run the file directly

python calculator.py

Python treats that file as the main entry point of the program, so: 

__name__ == "__main__"

The guarded block runs.

When you import the file

import calculator

Python loads the file as a module, so:

__name__ == "calculator"

The guarded block does not run.

Why This Is So Useful

This pattern gives one file two roles:

  1. It can act as a reusable module.
  2. It can act as a standalone program for testing or execution.

That makes your code cleaner and more reusable.

A Real Pythonic Structure

A common pattern is to write a main() function and call it inside the __main__ block. 

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def main():
    print("This is a simple calculator")

    x = int(input("Enter first number: "))
    y = int(input("Enter second number: "))

    print("Sum:", add(x, y))
    print("Difference:", subtract(x, y))

if __name__ == "__main__":
    main()

This is better because your main program logic stays organized inside a function instead of being scattered in the global body of the file.

Remember: write reusable code, and keep execution separate. That is the real point of __main__.
