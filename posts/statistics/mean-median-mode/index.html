Mean, Median, and Mode

Three ways to describe the center of a dataset—and how to choose the one that represents your data honestly.

August 30, 2026•Ahamed Learning Notes

Mean, median, and mode describe the center of data, but each answers a different question: What is the average? What is the middle? What is most common?

Lesson 1: Mean

What is the mean?

The mean, or average, is a value that represents the center of a dataset. Imagine the values as weights placed on a seesaw: the mean is the point where the seesaw balances.

Suppose the dataset is:

2, 4, 6, 8, 10
Mean = (2 + 4 + 6 + 8 + 10) / 5 = 6

Therefore, the average is 6.

Formula

μ = 1 n n ∑ i = 1 xi
  • xi is the i-th observation.
  • n is the total number of observations.
  • ∑ means add all the observations together.

Worked example

Consider the scores 90, 80, 70, 60, 100.

Sum = 90 + 80 + 70 + 60 + 100 = 400
Number of scores = 5
Mean = 400 / 5 = 80

Mean in Python

import numpy as np

scores = np.array([90, 80, 70, 60, 100])
print(np.mean(scores))

Output:

80.0

Why is the mean useful?

Suppose two hospitals have patients with these ages:

Hospital A: 20, 21, 22, 23, 24
Mean: 22

Hospital B: 10, 20, 30, 40, 100
Mean: 40

Hospital B has the higher average age, but its single 100-year-old patient has a large effect. This demonstrates that the mean is sensitive to extreme values, or outliers.

When should you use the mean?

Use the mean when:

  • The data are approximately symmetric.
  • There are no major outliers.
  • You want to summarize all observations with one number.

Mean in machine learning

You will encounter the mean throughout machine learning:

  • Feature centering: x' = x - mean
  • Standardization: (x - μ) / σ
  • Mean Squared Error: (1 / n) ∑ (y - ŷ)2
  • Gradient descent: averaging gradients over a batch.
  • Batch Normalization: using the batch mean.

Lesson 2: Median

What is the median?

The median is the middle value when the data are arranged in increasing or decreasing order. It divides the data into two equal halves: 50% of values are below it and 50% are above it. Unlike the mean, it is not affected much by outliers.

Odd number of observations

3, 5, [7], 9, 12

There are five values, so the middle value and median is 7.

Even number of observations

3, 5, 7, 9, 12, 15
      ^  ^

There is no single middle value, so average the middle two:

Median = (7 + 9) / 2 = 8

Mean vs. median: salaries

$30k, $35k, $40k, $45k, $500k
Mean = (30 + 35 + 40 + 45 + 500) / 5 = $130k

Most people do not earn close to $130k. After sorting the data, the middle salary is $40k, so the median is $40k. It better represents the typical person.

Why does the median resist outliers?

Start with 20, 25, 30, 35, 40:

Mean = 150 / 5 = 30
Median = 30

Now add the extreme value 1,000,000:

20, 25, 30, 35, 40, 1,000,000
Mean = 1,000,150 / 6 = 166,691.67
Median = (30 + 35) / 2 = 32.5

The mean changes dramatically, while the median changes only from 30 to 32.5.

Median in machine learning

1. Data preprocessing

Consider these house prices:

$100k, $150k, $200k, $250k, $50 million

A mean near $10 million would distort the typical price. The median, $200k, is more representative.

2. Missing-value imputation

Age: 21, 25, ?, 30, 35
Mean = (21 + 25 + 30 + 35) / 4 = 27.75
Median = (25 + 30) / 2 = 27.5

Median imputation is often preferred when the feature has outliers.

3. Computer vision

A median filter can remove noise from images. Consider a pixel neighborhood:

10  12  11
13 255  12
11  10  13

Sorted, the values are 10, 10, 11, 11, 12, 12, 13, 13, 255. The median is 12, so the noisy pixel value 255 can be replaced by 12.

Median in Python

import numpy as np

odd_data = np.array([3, 5, 7, 9, 12])
print(np.median(odd_data))   # 7.0

even_data = np.array([3, 5, 7, 9, 12, 15])
print(np.median(even_data))  # 8.0

Mean vs. median summary

PropertyMeanMedian
Uses all valuesYesNo
Sensitive to outliersYesNo
Good for symmetric dataYesYes
Good for skewed dataNoYes

Important rule: for a symmetric distribution, the mean is usually better. For a skewed distribution, the median is usually better.

Lesson 3: Mode

What is the mode?

The mode is the value that appears most frequently. Unlike mean and median, it does not require numerical data and can describe categories or labels.

For 2, 3, 3, 5, 7, 3, 8:

ValueFrequency
21
33
51
71
81

The value 3 appears most often, so the mode is 3.

Types of mode

  • Unimodal: 1, 2, 2, 3, 4 has one mode, 2.
  • Bimodal: 1, 2, 2, 3, 4, 4 has two modes, 2 and 4.
  • Multimodal: 1, 1, 2, 2, 3, 3, 4 has three modes, 1, 2, and 3.

Mode with categorical data

The mode is Python. Mean and median do not make sense because these categories have no numerical meaning.

Mean vs. median vs. mode

For 1, 2, 2, 3, 10:

Mean = (1 + 2 + 2 + 3 + 10) / 5 = 3.6

The ordered middle value is 2, and the most frequent value is also 2.

MeasureMeaningResult
MeanAverage value3.6
MedianMiddle value2
ModeMost common value2

When should you use the mode?

  • Categorical data: the most common color, country, class label, or disease type.
  • Discrete data: in 0, 1, 2, 2, 3, 2, 4, the mode is 2 children.
  • Repeated values: in ratings 5, 5, 4, 5, 3, 5, 4, the mode is 5 stars.

Mode in machine learning

1. Missing-value imputation

In Red, Blue, Red, ?, Green, Red, the missing category can be replaced with the mode, Red.

2. Classification and majority voting

For predictions Dog, Dog, Cat, Dog, Bird, the majority prediction is Dog. This idea is used in Random Forests and other ensemble methods.

3. Image processing

Cat Cat Cat
Cat Dog Cat
Cat Cat Cat

The neighboring mode is Cat, so the noisy Dog label may be corrected to Cat during image segmentation.

Mode in Python

Using NumPy:

import numpy as np

data = np.array([2, 3, 3, 5, 7, 3, 8])
values, counts = np.unique(data, return_counts=True)
mode = values[np.argmax(counts)]
print(mode)  # 3

Using SciPy:

from scipy import stats

data = [2, 3, 3, 5, 7, 3, 8]
result = stats.mode(data)
print(result.mode)  # 3

The central lesson

  • Mean: What is the average?
  • Median: What is the middle?
  • Mode: What is most common?
Statistical insight: a statistician does not ask, “Which one is best?” The better question is, “Which one describes my data correctly?”
